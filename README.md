# Adventure_works
I utilized Power Query to clean data and applied Advanced Excel (VLOOKUP, Pivot Tables, Slicers) to develop an interactive dashboard analyzing global sales performance across six countries. By transforming complex datasets into clear visuals, I tracked key metrics like revenue, profit margins, and seasonal trends.
