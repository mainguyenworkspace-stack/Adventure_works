# Adventure_works
Project: Global E-Commerce Sales & Business Performance Dashboard
Tools: Advanced Excel (Power Query, Data Modeling, Pivot Tables)

Objective: Engineered an interactive dashboard analyzing a multi-relational retail dataset to monitor global operational health, customer purchasing behavior, and regional profitability.

Technical Execution: * Employed Power Query to ETL (Extract, Transform, Load) over 60,000 transactional records (FactInternetSales).

Built a Star Schema data model, integrating fact data with multiple dimensions (DimCustomer, DimProduct, DimGeography, DimDate) to enable multi-layered analysis.

Designed dynamic visualizations with advanced formulas and cross-filtering slicers for tracking macro-KPIs (Revenue, Profit Margin, YoY Growth).
